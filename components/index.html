Tokens The single source of truth lives in tokens.css, mirrored for TypeScript in tokens.ts. Components reference var(--rc-*) or Tailwind theme utilities. A CI check (bun run lint:tokens) fails raw hex or pixel literals anywhere else.

Typography Display headings in Cooper Black with an Avenir Next fallback, body text in Avenir Next, and links with a thick offset underline. Headings render the requested level so the document outline stays meaningful.

Theming Themes are a data-theme attribute on <html>. Components read var(--rc-*), so they follow automatically. The toggle persists to localStorage and falls back to your OS setting. 
import { applyTheme, getInitialTheme } from "./theme";

applyTheme(getInitialTheme()); // "light" | "dark"
// any [data-theme-toggle] button flips and persists it
Accessibility The system targets WCAG 2.2 AA: text pairs hold at least 4.5:1, focus indicators at least 3:1, and interactions stay keyboard-operable.
what is covered
  • Native elements under every component (button, select, headings, links)
  • Visible thick focus ring on all interactive elements
  • Skip link, landmarks, labelled sections and nav
  • Decorative dots and grid hidden with aria-hidden
  • Status conveyed in words, never color alone
  • Reduced-motion support and forced-colors adjustments
